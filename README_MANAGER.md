# Stream Live Hub - Manager Guide

## 👋 Welcome, Platform Manager!

This guide will help you manage the Stream Live Hub platform without needing technical knowledge. Everything you need is available through the admin dashboard.

## 🔐 Accessing the Admin Panel

1. Go to your website's URL
2. Click **"Login"** at the top right
3. Enter your admin email and password
4. You'll be automatically redirected to the admin dashboard

## 📊 Admin Dashboard Overview

Your dashboard shows:
- **Total Users**: Number of registered users
- **Active Creators**: Creators currently streaming
- **Revenue Today**: Money earned today
- **Pending Payouts**: Withdrawals awaiting approval

## 👥 Managing Users

### View All Users

1. Click **"Users"** tab in the admin panel
2. You'll see a list with:
   - Username
   - Email
   - Account type (Viewer/Creator)
   - Registration date
   - Status

### Find a Specific User

1. Use the search box at the top
2. Type the username or email
3. Results appear instantly

### Ban/Unban Users

1. Click on a user's name
2. Click the **"Ban User"** button
3. Enter a reason (optional)
4. Confirm the action

To unban:
1. Find the banned user
2. Click **"Unban User"**
3. Confirm

### Reset User Password

1. Find the user
2. Click **"Reset Password"**
3. A reset email will be sent to them automatically

## 🎥 Managing Creators

### View All Creators

1. Click **"Creators"** tab
2. See all creators with:
   - Display name
   - Subscriber count
   - Total revenue
   - Live status (online/offline)

### Feature a Creator

Featured creators appear at the top of the homepage:

1. Find the creator
2. Toggle the **"Featured"** switch
3. Changes apply immediately

### View Creator Stats

1. Click on creator's name
2. See detailed statistics:
   - Total subscribers
   - Average viewers
   - Revenue this month
   - Stream history

## 💰 Financial Management

### View All Transactions

1. Click **"Transactions"** tab
2. Filter by:
   - Date range
   - Transaction type (Subscription/SuperChat)
   - Status (Pending/Approved/Failed)
   - Creator

### Approve Payout Requests

When creators request withdrawals:

1. Go to **"Payouts"** tab
2. You'll see pending requests with:
   - Creator name
   - Amount requested
   - Bank account info
   - Current balance

To approve:
1. Click **"Review"** on the request
2. Verify the bank details
3. Click **"Approve Payout"**
4. Enter admin notes (optional)
5. Confirm

The payment will be processed automatically via Mercado Pago.

To reject:
1. Click **"Review"**
2. Click **"Reject"**
3. Enter rejection reason
4. Creator will be notified

### Adjust Platform Settings

1. Go to **"Financial Settings"** tab
2. You can change:
   - **Subscription Price**: Monthly subscription cost (default: R$29.90)
   - **Creator Percentage**: How much creators keep (default: 60%)
   - **Platform Percentage**: Platform's cut (default: 30%)
   - **Affiliate Percentage**: Referral bonus (default: 10%)

3. Click **"Save Changes"**
4. New rates apply to future transactions only

**Note**: Percentages must add up to 100%!

## 📧 Managing Communications

### Send Notifications

1. Go to **"Notifications"** tab
2. Click **"New Notification"**
3. Fill in:
   - Recipients (All Users/Creators Only/Specific User)
   - Title
   - Message
4. Click **"Send"**

Notifications appear in users' notification bell icon.

### View Email History

1. Go to **"Email History"** tab
2. See all sent emails:
   - Password resets
   - Subscription confirmations
   - Payout approvals
3. Click on any to see full content

## 🎨 Managing Homepage

### Add/Remove Categories

Categories help users find creators:

1. Go to **"Categories"** tab
2. See existing categories (Gaming, Music, Talk Shows, etc.)

To add:
1. Click **"Add Category"**
2. Enter category name
3. Choose icon (optional)
4. Click **"Create"**

To remove:
1. Click ❌ next to category
2. Confirm deletion
3. Creators in that category will be uncategorized

### Feature Live Streams

Make specific streams appear first:

1. Go to **"Featured Streams"** section
2. Click **"Add Featured Stream"**
3. Select creator
4. Choose position (1-10)
5. Set duration (how long to feature)
6. Click **"Feature"**

## 📈 Analytics & Reports

### View Platform Statistics

1. Click **"Analytics"** tab
2. See graphs showing:
   - User growth over time
   - Revenue trends
   - Popular creators
   - Peak streaming hours

### Export Reports

1. Click **"Export"** button
2. Choose report type:
   - User Report (all users)
   - Revenue Report (financial data)
   - Creator Report (creator stats)
3. Select date range
4. Click **"Download CSV"**

The file opens in Excel/Google Sheets.

## 🛡️ Moderation Tools

### Review Flagged Content

Users can report inappropriate streams/messages:

1. Go to **"Reports"** tab
2. See all reports with:
   - What was reported
   - Who reported it
   - Timestamp
   - Reason

To take action:
1. Click **"Review"**
2. View the context
3. Choose:
   - **Dismiss**: If it's not a violation
   - **Warn Creator**: Send warning message
   - **End Stream**: Stop the current stream
   - **Ban Creator**: Permanently ban account

### Monitor Chat Activity

1. Go to **"Live Chat Monitor"**
2. See all active chats across all streams
3. Filter by:
   - Creator
   - Keywords (to find specific topics)
4. Click on any to see full conversation

To moderate:
1. Click on message
2. Options:
   - **Delete Message**
   - **Timeout User** (1 min to 24 hours)
   - **Ban User from Room**
   - **Ban User from Platform**

## 🔔 Notifications & Alerts

You'll be notified about:
- New payout requests (email + dashboard)
- User reports (immediate notification)
- Failed payments (daily summary)
- New creator applications (if enabled)

To manage notification settings:
1. Click your profile (top right)
2. Go to **"Notification Settings"**
3. Toggle email alerts on/off for each type

## ❓ Common Tasks

### A Creator Can't Go Live

1. Go to **"Creators"** tab
2. Find the creator
3. Check their status:
   - Is account active?
   - Are they banned?
   - Do they have streaming permissions?
4. Click **"Troubleshoot"** for detailed diagnostics

### User Can't Subscribe

1. Go to **"Transactions"** tab
2. Search for user's email
3. Check recent failed transactions
4. Common issues:
   - Payment method declined
   - Technical error
5. Click **"Retry Payment"** or **"Contact Support"**

### Change Subscription Price

1. Go to **"Financial Settings"**
2. Update **"Subscription Price"**
3. Click **"Save"**
4. **Important**: Only new subscriptions use new price

## 🆘 Getting Help

### Platform Issues

If something isn't working:
1. Check **"System Status"** page
2. Review recent error logs
3. Contact technical support with:
   - What you were trying to do
   - Error message (if any)
   - Screenshot (helpful!)

### Payment Issues

For payment problems:
1. Go to **"Transactions"** tab
2. Find the transaction
3. Click **"View Details"**
4. Click **"Contact Payment Support"**
5. Mercado Pago team will investigate

### Creator Support

When creators need help:
1. Go to **"Creator Support"** tab
2. See all open support tickets
3. Click on ticket to respond
4. Your response is emailed to them

- **Never share** your admin password
- **Always log out** when done
- **Use strong passwords** (12+ characters, mix of letters/numbers/symbols)
- **Enable 2FA** (two-factor authentication) in settings
- **Review access logs** regularly (Settings → Access Logs)
